# 누드TV 발행 시스템

스포츠 15개 리그(야구·축구·농구·배구)의 일정과 결과를 모아 **카드 이미지**로 만들어
**텔레그램 채널에 자동으로** 올립니다.

## 한눈에

| 항목 | 내용 |
|---|---|
| 무엇을 보내나 | 오늘의 경기(종목별) · 경기 문패 · 분석 · 선발 명단 · 승부 예측 투표 · 득점/구간/종료 속보 · 기록실 · 순위표 · 리그 정리판 |
| 어디에 | 채널에는 문패까지, 세부는 **그 경기 문패의 댓글**에 |
| 어디서 도나 | GitHub Actions (공개 저장소라 실행시간 무료) |
| 얼마나 자주 | 실행 하나가 약 2시간 살면서 **2분마다** 일함 (자기 자신을 이어 붙여 24시간 연속) |
| 비용 | 0원 |

## 자세한 설명서

**운영가이드.md** 를 보세요. 켜는 법, 매일 무슨 일이 일어나는지, 문제가 생겼을 때 무엇을 확인하는지가 전부 들어 있습니다.

## 꼭 지킬 것

**state 폴더를 지우지 마세요.** "무엇을 언제 보냈는지"의 유일한 기록이라, 지우면 같은 카드를 구독자에게 다시 보냅니다.

**이 저장소는 공개입니다.** 토큰·채널ID·운영 정보가 담긴 파일을 올리지 마세요. 파일을 추가한 뒤에는 `python g1/verify_public.py` 로 확인하세요.
