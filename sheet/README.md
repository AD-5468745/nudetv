# ⚠️ 이 폴더의 xlsx는 저장소에 넣지 않는다

`누드TV_발행_제어판.xlsx`에는 **텔레그램 채널 ID가 평문으로** 들어 있다.
이 저장소는 공개이고, 대장에서는 같은 값을 `channel_ref()` 단방향 해시로 감춘다.
**기준이 두 곳에서 다르면 안 된다** — 그래서 시트 파일 자체는 커밋하지 않는다.

`g1/verify_public.py`가 이것을 실제로 잡았다(2026-09-08):
```
FAIL  실제 채널 ID가 없다 (대장은 지문으로 저장)
```

필요하면 `python3 sheet/build.py`로 언제든 다시 만든다 — 값은 `contract.py`에서 뽑으므로
만들 때마다 그 시점의 현실을 정확히 비춘다.
